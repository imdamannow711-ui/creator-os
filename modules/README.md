# Creator OS Next Modules

These modules are staged on `build/creator-os-next` and are not loaded by the live app yet.

- `creator-os-next-config.js` — approved production/compliance rules
- `media-vault.js` — media categorization and cleanup recommendations
- `content-gap-demand.js` — 1000+ priority, 750–999 watchlist, below 750 ignored
- `hook-ranking.js` — separates engagement from verified video-attributed sales
- `hands-only-quick-create.js` — 7–10 second hands-only package generator
- `youtube-amazon.js` — YouTube Shorts queue + Amazon Associates tracking
- `product-picks.js` — DONE RITE Product Picks catalog
- `performance-engine.js` — cross-platform analytics and attribution
- `cross-platform-package.js` — platform-specific packaging from one shoot
- `daily-hq.js` — daily summary and next-action logic
- `ui-loader-dev.js` — development-only module list

The live React bootstrap remains untouched until a staged UI integration is verified.
